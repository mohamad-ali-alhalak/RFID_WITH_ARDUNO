# Smart RFID Access Control System | نظام التحكم بالوصول عبر الـ RFID

مشروع بسيط ومثالي للمبتدئين لتعلم كيفية استخدام قارئ البطاقات الذكية **MFRC522** مع لوحة **Arduino Uno** للتحكم في الوصول عن طريق فحص هوية البطاقة وتشغيل مؤشرات ضوئية (LEDs) وصوتية (Buzzer).

## 🔌 مخطط التوصيل (Wiring Diagram)
يمكنك العثور على مخطط التوصيل الواضح داخل مجلد `schematics/wiring_diagram.png`.

### جدول التوصيل (Pinout Table):

| MFRC522 Pin | Arduino Pin |
|---|---|
| VCC | 3.3V |
| RST | D9 |
| GND | GND |
| MISO | D12 |
| MOSI | D11 |
| SCK | D13 |
| SDA (SS) | D10 |

## 🚀 طريقة التشغيل (How to Use)
1. قم بتحميل مكتبة `MFRC522` في برنامج Arduino IDE.
2. افتح ملف الكود الموجود في `RFID/RFID.ino`.
3. ارفع الكود إلى لوحة الأردوينو الخاصة بك.

## 🛠️ القطع المستخدمة والمكونات (Bill of Materials)

| اسم القطعة (Component) | الكمية (Qty) | الوصف / الوظيفة (Description) |
| :--- | :---: | :--- |
| **Arduino Uno** | 1 | لوحة التحكم الرئيسية بالمشروع |
| **MFRC522 RFID Module** | 1 | قارئ البطاقات والرموز الذكية بتردد 13.56 MHz |
| **RFID Card / Key Fob** | 1 | البطاقة أو الميدالية الذكية المراد فحصها |
| **Buzzer (5V)** | 1 | طنان صوتي لإصدار تنبيهات عند القبول أو الرفض |
| **Green LED** | 1 | مؤشر ضوئي يدل على قبول البطاقة (Access Granted) |
| **Red LED** | 1 | مؤشر ضوئي يدل على رفض البطاقة (Access Denied) |
| **Yellow LED** | 1 | مؤشر ضوئي يدل على أن النظام جاهز وبانتظار القراءة |
| **Resistors (220 ohm)** | 3 | مقاومات لحماية الليدات من الاحتراق |
| **Jumper Wires** | - | أسلاك لتوصيل القطع ببعضها حسب المخطط |
